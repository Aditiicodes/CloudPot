# findings/

Templates. The operator fills them from real output; nothing here is
pre-populated and no `[FILL]` marker should be left in a published report.

| File | What it is |
| --- | --- |
| `REPORT.md` | The written findings report. Every number cites the query or script that produces it. |
| `attack_ttps.md` | ATT&CK mapping. The Observed column starts empty on purpose — `not observed` is a valid and common answer. |
| `iocs.csv` | Header row only. Regenerated by `make parse`. |

`make parse` writes `iocs.csv` and `summary.json` here, overwriting the
template header. That is intended.

`findings/raw/` is where `make fetch` puts the logs synced from S3. It is
gitignored: it holds attacker source addresses and credential guesses, and a
public repository is not the place for a week of unreviewed raw telemetry.
